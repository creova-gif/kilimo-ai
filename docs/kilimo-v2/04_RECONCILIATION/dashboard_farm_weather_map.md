- **Matrix rows: 46** (34 Figma frames + 12 Git-only / cross-cutting items). Decisions: **KEEP FIGMA 6 · KEEP GIT 4 · MERGE 13 · REDESIGN 6 · REMOVE 10 · ADD 7** (counts re-computed from the table at the end of this task).

- **Legacy strengths to keep:** `lib/weather.ts` + `useWeather` + `app/forecast.tsx` are already honest (unconfigured/error/unknown-location/empty states, no invented hourly/UV); `useTasks` offline-queue design; `MapViewWrapper` native/web split; honest GPS and VRA "not live" gates; `tasks.tsx` is the only screen with proper bilingual a11y labels.

Figma itself is inconsistent across frames (slot-3 icon varies leaf/sparkle/chip; Soko/Mimi icons vary; some frames add a camera FAB "Piga Picha") — one variant must be chosen.

## What Git does better (preserve)

1. **Honest weather states.** `forecast.tsx` handles unconfigured, API error, unknown-location, network and empty forecast; refuses to backfill fake hourly/UV (`:250-283, :357-401`). Home's `WeatherWidget` also short-circuits to "data not available" (`index.tsx:1596-1611`). Figma has no unavailable/error frame at all.
2. **Timezone-correct daily bucketing** in `lib/weather.ts` (local-date keys via `city.timezone`), 30-min cache and retries in `useWeather`.
3. **Offline-first task model**: optimistic updates, `syncQueue`, and `processSyncQueue` really writes `task_complete` items to `tasks` (documented fix in `lib/offline.ts`). Figma draws no offline behaviour.
4. **Truthful gates on unbuilt integrations**: `VRA_EQUIPMENT_SYNC_LIVE=false`, "GPS not enabled" alert, no faked coordinates (`map.tsx:113-142`).
5. **`tasks.tsx` accessibility and bilingual copy** (24 SW/EN `accessibilityLabel`s, day cells labelled with full dates) — every other domain screen is English-only or Swahili-only.
6. **`MapViewWrapper` platform split**, back-navigation fallbacks (`router.canGoBack() ? back : replace('/')`), pull-to-refresh that forces a queue sync.
7. **"No crops registered → complete profile" card** on Home gives new users a next step (Figma Today has no equivalent).
8. **Feature routing table + role gating** in `features.tsx` (`ALL_FEATURES`).

## What Figma does better

1. **Information architecture & density**: Today (≤2 alerts, one checklist, one AI card) and Features Hub as a searchable icon grid are far more legible for low-literacy, one-thumb use than Home's 5,600-line stack of bento cards, carousels and modals.
2. **Plot-first Shamba view** (`89:2006`) — name, area, crop, progress at a glance — versus a satellite map of four zones.
3. **Missing capabilities the farmer actually needs**: Harvest Log, crop plan creation with computed harvest date, crop lifecycle timeline, pest reporting, planting-window timeline, hourly table (implementable from 3-hour data).
4. **Consistent nav and tokens**: 5-tab bar with raised centre action, olive palette tokens now in `constants/Theme.ts`; legacy tab bar is Swahili-only and its "+" is a launcher, not a task.
5. **Structured crop facts** (`160:2472`): season, cycle, temperature, water, stages, pests — scannable static data.
6. **Empty states** (No Farms / No Tasks) — legacy has none because fabricated data always fills the screens.
7. **Mixed EN/SW labelling** (`Ratiba ya Msimu (Planting Windows)`) shows bilingual intent, but note it is bilingual *in one string*, not switchable — needs resource layer (`lib/i18n`, G-009).

## Journey consolidation

**Target journey (Dashboard → Farm → Plot → Crop → Activity → Recommendation):**
1. **Nyumbani (Today)** — greeting/date, alerts from real weather, today's tasks, one AI card / ask input. Bell → notifications. Header shows farm name + region from `farmer_profiles`.
2. **Shamba (Overview v2)** — list of plots (cards) + season summary (area, active plans). "+ Ongeza Shamba" → Add plot. Map toggle in header → Map View.
3. **Plot detail (Field Detail)** — crop, planting date, stage, days to harvest, tasks for this plot, plot weather, actions: *Anza mpango wa mazao*, *Rekodi mavuno*, *Ripoti wadudu*, *Piga picha (scan)*.
4. **Crop** — Crop Library (reference) ↔ Crop Plan create (plot + crop + planting date) ↔ Crop Lifecycle (stages).
5. **Activity** — Tasks (list/create) + Calendar (one screen, week/month); Harvest Log; Pest report.
6. **Recommendation** — only where a real basis exists: weather-derived tips, crop-calendar suggestions, RAG answers with real citations from Sankofa. Shown inside Today/Plot detail as small cards with "kwa sababu …" — not a separate engine screen.

**Weather:** entry points — Today alert card, Today weather line, plot detail weather card. `/forecast` (daily + summary) → tap a day/"Saa kwa saa" → Hourly Detail (3-hourly). Alerts screen only when there is at least one threshold-derived alert (else the empty positive state inside `/forecast`). Radar removed.

**Map/GPS/polygon:** `/map` opens from Shamba header and plot detail ("Ona kwenye ramani"). Phase 1: satellite base, plot pins from stored point + area, locate-me with permission flow, search by plot name. Phase 2: polygon draw → GeoJSON. Layers (NDVI/moisture/temp) removed until data exists.

**De-duplications:** Home→Today; Overview→v2; Map→Map View; Forecast→v2; Daily Actions folded into Today+Tasks; `calendar.tsx` + `tasks.tsx` calendar view → one `Calendar`; VRA Setup+Map → removed; two No-Farms frames → one.

## Localization & accessibility notes

- **Language state:** `useKilimoStore.language` (`sw` default) exists, and `lib/i18n` (typed EN/SW, key-parity test) landed in `ae07e58`; **none of this domain's screens use it** — they use inline `language === 'sw' ? … : …` or nothing. Swahili-only screens: `crop-library.tsx` ("Maktaba ya Mazao", all catalog fields), `crop-planning.tsx`, most of `tasks.tsx` body copy, tab labels (`_layout.tsx`), `weather swTip`/`conditionLabel` (OpenWeather is asked `lang: 'sw'` even for EN users, `lib/weather.ts` `ow()`); English-only: `fields.tsx` a11y labels ("Menu", "Notifications", "Search Fields"), `map.tsx`/`forecast.tsx`/`vra-setup.tsx` a11y labels, "Field Not Found", "OFFLINE (n Q)". Requirement: every string via `useT`; pass `lang` to OpenWeather from the app language; catalog fields as `{sw,en}`.
- **Figma text is Swahili with English glosses in parentheses** (e.g. "Ratiba ya Msimu (Planting Windows)") — treat glosses as design notes, not shipped copy.
- **Units:** Tanzanian smallholders commonly speak in **ekari** (acres) and gunia/mfuko (bags) — Figma mixes "Ekari 2.4", "Eka 1.2", "Hekta 1.2", "kg/eka", "ha" across frames; `farmer_profiles.farm_size_acres` is acres. Pick one primary (acre) with a ha toggle; bags need an explicit kg conversion. "Eka"/"Ekari" spelled inconsistently.
- **Dates:** show localized names ("22 Ago 2026"), never `12/03/2026` (Figma `160:2115`); week starts Monday (Figma) vs Sunday (legacy `DAYS_SW = J A J A A I J`, `calendar.tsx:92` — Sunday-first). Use device locale + explicit `Africa/Dar_es_Salaam` for forecast days.
- **Touch targets/legibility:** legacy tab items ≈ 68×(34+label); Figma nav labels are 11 pt, hourly chips ~44 wide, filter chips ≈ 32 pt tall (`14:2198`) → use `Chip size="md"` (≥44 pt per `FIGMA_COMPONENT_MAP`). Muted gray-on-tinted text on Figma cards (`#606C55` on `#F2F5EF`, small 11–12 pt) is borderline; verify with the token contrast tool before shipping (not measured here). Weather card on dark-green header uses light-green 24 °C sublabels — check.
- **Icon-only controls without text**: Map View (`106:1230`) zoom/locate/layers are icons — give each an accessible label (legacy has 6 English labels, `map.tsx:171-294`) in both languages. The map itself is not screen-reader navigable — provide the list alternative (plot list) and announce selection changes.
- **Charts** (temp line, rain bars, wind compass, lifecycle line): supply a text summary/`accessibilityValue` ("Kesho 29°, mvua 20 %") and don't use colour alone (Figma red/green polygon states in `106:1612` — removed anyway).
- **Voice:** legacy "voice guidance" in `map.tsx` is web-only speech; low-literacy users are a real target (Sankofa has `ai-voice.tsx`), but reuse that owner's TTS/STT instead of fake timers.
- **Low bandwidth:** Unsplash remote images (`crop-library.tsx`), BlurView-heavy cards on `forecast.tsx` (dark glass, hard-coded lime `#a3e635` outside the token set) — replace with token cards; cache last forecast in AsyncStorage (React Query has no persister configured for weather).
- **Reduced motion:** `hooks/useReducedMotion.ts` now exists; Home/Fields animate constantly (`withRepeat` pulses in `fields.tsx:69-78`, carousel autoplay every 6 s `index.tsx:1906-1911`) — respect it; autoplaying crop carousel is also an a11y issue.
- **Screen reader order** of Today: alerts first (announce with `AlertCard announce`), then tasks.
